# Law Chatbot – Contract Law Definitions Assistant

**Law Chatbot** is a Python-based chatbot designed to provide basic explanations of key **contract law concepts**. This project is part of a professional portfolio, showcasing how Python programming can be applied to the **legal-tech** field.

> ⚠️ **Educational Use Only**: This chatbot is meant for educational purposes only. It does not provide legal advice or interpret complex legal language.

---

## ⚖️ Features

- **Contract Law Definitions**: Offers definitions of important legal concepts such as **offer**, **acceptance**, **remedies**, etc.
- **Interactive CLI Chatbot**: Users can ask free-text questions and receive predefined responses.
- **Handles Variations**: Understands both singular and plural forms of key legal terms.
- **Beginner-Friendly**: No advanced AI or legal training data required — a great example of a rule-based chatbot.

---

## 🧠 Topics the Chatbot Can Respond To

- **Offer**
- **Acceptance**
- **Consideration**
- **Breach of Contract**
- **Contractual Capacity**
- **Void and Voidable Contracts**
- **Remedies (e.g., damages, specific performance)**
- **Terms and Conditions of a Contract**
- **Elements or Parts of a Contract**

The chatbot recognizes plural and alternate forms (e.g., "remedy" vs. "remedies", "contract" vs. "contracts").

---

## 🚫 Limitations

This chatbot is a **keyword-matching assistant**, not an AI language model. It does **not**:
- Provide legal advice or case-specific interpretation
- Process complex or jurisdictional legal issues
- Hold multi-turn conversations
- Use natural language processing or AI models

> 🛠️ This tool is for educational demonstration and portfolio use only.

---

## 💻 Installation

1. **Clone the repository**  
   ```bash
   git clone https://github.com/yourusername/law-chatbot.git
   ```
2. **Navigate to the project directory**  
   ```bash
   cd law-chatbot
   ```
3. **Run the chatbot**  
   ```bash
   python legal_bot.py
   ```

---

## 💬 Usage

Once the script is running, you can ask the chatbot questions like:
- “What is an offer in contract law?”
- “Tell me about breach of contract”
- “What is consideration in a contract?”

Type `'exit'` or `'quit'` to stop the chatbot.
